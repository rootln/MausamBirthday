A LITTLE MONSOON MAGIC — STANDALONE SOURCE

Files
  index.html  — complete page structure and birthday copy
  styles.css  — all layouts, rain, ceremony, envelope, reveal, and responsive animation styles
  script.js   — ceremony logic, audio fade, one-by-one reveals, stardust, gallery, and confetti

Preview
  Keep all three files in the same folder and open index.html in a modern browser.
  For the most reliable local preview, run any static server in this folder.

Hosting
  Upload the three files together to GitHub Pages, Netlify, Vercel, Cloudflare Pages,
  or any other static host. No framework, build command, or package installation is required.

External assets
  The three supplied photos and the supplied song remain linked through their Cloudinary URLs.
  Internet access is therefore required for the photos and music to load.

Music
  Browsers require a user gesture before audio can begin. The final “Music, softly” ceremony
  step provides that gesture and fades the track in to a maximum volume of 13%.
